1. 구조체 변수 대입과 복사에 대한 설명으로 옳지 않은 것은

① C 언어에서는 같은 자료형의 구조체 변수 간 대입이 가능하며, 대입 방법은 기본 자료형 변수 간 대입과 유사하다.
② '전체 복사'는 소스 구조체의 각 멤버를 개별적으로 복사하는 것이 아니라 구조체 전체를 한 번에 복사한다.
③ '깊은 복사'는 int형, float형, char형 배열 등과 같은 기본 자료형의 멤버에 대해 적용된다.
④ '얕은 복사'는 포인터 멤버가 있는 경우 포인터가 가리키는 실제 데이터까지 모두 함께 복사되는 것을 의미한다.

#include <string.h>

struct Person {
    char name[50];
    int age;
};

void printPerson(struct Person p) {
    printf("Name: %s, Age: %d\n", p.name, p.age);
}

void updateAge(struct Person p) {
    strcpy(  [      ]  , "Yun");
    p.age = 22;
}

    printPerson(p1);
    updateAge(p1);
